# Wishful

Wishful ist eine Social-App für iOS und Android, in der man Wünsche als Posts teilt und andere sie erfüllen können.

Man postet einen Wunsch mit Titel und Produktlink, Preis und Bild werden automatisch erkannt. Wer den Wunsch im Feed entdeckt, kann ihn direkt in der App bezahlen. Wishful bestellt das Produkt und lässt es an den Empfänger liefern, dessen Adresse dabei verborgen bleibt.

**Status:** In Planung, siehe [Projektplan](Wishful-Plan.md).
